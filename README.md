# 원소 샌드박스

<p align="center"><img width="900" src="docs/screenshot.png" alt="샌드박스에서 터지는 화염 왕관"></p>

**<a href="https://sigco3111.github.io/LinearAbilityExtThreeJS/" target="_blank">🎮 라이브 플레이 — sigco3111.github.io/LinearAbilityExtThreeJS</a>**

스킬샷 VFX 샌드박스를 **Three.js**, **Vite**, 직접 작성한 **GLSL**로 만들었습니다.

![화염 왕관이 샌드박스에서 분출하는 모습](docs/screenshots/hero.jpg)

일곱 가지 시전 능력과 다섯 가지 조준 방식을 지원합니다. 키를 눌러 능력을 들고, 그에 맞는 조준 표시가 나타나며, 마우스로 흔들어 방향을 잡고, 클릭으로 시전합니다. **라인 시전**은 화살표로 직선 방향을 가리키는 한 종류, **원거리 시전**은 굵은 경계선이 마우스를 따라다니며 원형 범위가 얼마나 될지 알려주는 세 종류, **관문 시전**은 바닥에 세워둘 구조물을 짓는 한 종류, **고리 시전**은 바닥에 누워 만들었다가 경첩으로 세우는 한 종류, **필기 시전**은 공중에 크기를 정해 그 자리에 뚫는 한 종류입니다.

**Q — 화염 왕관.** 화염의 선이 바닥을 가로질러 목표 지점까지 달려가고, 원 안의 바닥이 갈라져 용암이 되며, 타오르는 칼날의 고리가 균열에서 솟아옵니다. 바깥쪽으로 기울고, 서로 얽히도록 부채꼴로 펼쳐지며, 높이가 들쭉날쭉한 채로 서서 타고, 중앙의 열기둥 위로 숯을 위로 뿜어냅니다. 결국 **다 타서** 끝납니다 — 칼끝부터 바닥까지 불이 역으로 내려오며 그 자리엔 재만 남습니다. 발자국 한가운데는 일부러 비워둡니다. 시전의 식별성은 **안을 들여다보는 벽**에 있고, 디스크를 채워버리면 고리처럼 읽히지 않기 때문입니다.

![화염 왕관 — 그 분화구 위에 서 있는 타오르는 칼날 고리](docs/screenshots/pyre-crown.jpg)

**E — 크라켄 왕관.** 검은 물이 미끄러지듯 목표 지점까지 흘러가고, 원 안의 돌이 무너지며, 문어의 다리가 그 균열에서 기어 나옵니다. 휘감긴 채로 올라오다가 펴지면서 뒤로 젖혀지고, 결국 **발자국 중앙을 내리찍습니다**. 매번 내려칠 때마다 돌과 물보라와 먹물을 튀기는 데, 한꺼번에 동시에 떨어지지 않고 천둥이 구르는 듯 시간차가 있고, 마지막에 모든 팔이 동시에 내리치며 균열 속으로 다시 기어 들어갑니다.

![크라켄 왕관 — 균열에서 치켜 올라오는 문어 다리의 고리](docs/screenshots/kraken-crown.jpg)

**R — 전기 구체.** 전류의 선이 바닥을 갈며 목표 지점까지 채찍처럼 내리꽂히고, 떨어진 자리의 바닥이 갈라지며, 억제 플랫폼이 펼쳐지고, 칠흑처럼 매끈한 구체가 한가운데에서 솟아올라 떠 있습니다. 방을 거울처럼 비추고, 프레넬 빛이 둘레를 감싸며, 전기가 표면 위를 납작하게 기어가고, 표면에서 아크가 찢어져 나갑니다. 결국 안으로 무너지며 사라집니다.

![전기 구체 — 떠 있는 구체에서 찢어져 나가는 아크](docs/screenshots/electrical-sphere.jpg)

**F — 대지의 첨탑.** 유일한 라인 시전입니다. 목표한 선을 따라 진행하는 전면 뒤로 돌판의 지각이 깔리고, 균열 파동이 그 뒤를 따라 지각을 부수며, 그 틈 사이로 바위가 솟아오릅니다. 그리고 선이 끝나는 지점에서 **석탑이 바닥에서 올라오며, 받침 둘레로는 바위들이 어깨처럼 밀려 올라옵니다**.

![대지의 첨탑 — 선의 끝에서 올라오는 탑](docs/screenshots/earthen-spire.jpg)

**V — 녹색 관문.** 첫 번째 관문 시전입니다. 녹빛 용접선이 목표 지점까지 선을 따라 달려가고, 발자국 바깥쪽 바닥에서 깎인 블록들이 빠져나와 자기 자리까지 들어 올려지며 양 벽주가 동시에 쌓여 올라가고, 바깥 열이 안쪽 열보다 느리게 올라가며, 키스톤이 마지막에 자리 잡으면서 한 번 크게 흔들립니다. 그리고 관문이 입구를 가득 채우며 **다른 관문이 세워질 때까지 꺼지지 않고** 켜져 있습니다. 그동안 서 있던 관문은 키스톤부터 다시 풀리며 분해됩니다.

![녹색 관문 — 키스톤이 자리 잡고 관문이 켜진 모습](docs/screenshots/verdant-gate.jpg)

**X — 격류의 고리.** 첫 번째 고리 시전입니다. 빛의 조수가 선을 따라 흘러가고, 고리는 바닥에 **누운 채로 단조**됩니다 — 분절이 지면 평면에서 넓은 궤도로부터 안쪽으로 소용돌이쳐 들어오며, 발부터 시작해 위로 올라가며 잠기고, 양쪽 원호가 마루에서 만나며 닫힙니다. 룬 문자의 띠가 한 글자씩 켜지고, 완성된 고리가 자기 측 방향축을 경첩 삼아 바닥에서 일어나 수직보다 살짝 더 지나가도록 안착합니다. 그리고 지평선이 한가운데에서 바깥쪽으로 동공처럼 열리며 림에 부딪히고는 그대로 켜져 있습니다.

![격류의 고리 — 일어서고 지평선이 열린 고리](docs/screenshots/tidewrought-ring.jpg)

**Z — 불꽃 차원의 문.** 첫 번째 필기 시전입니다. 검은 디스크가 **내려침**으로 생겨납니다 — 원의 발치에서 점화가 시작되어 한 바퀴를 다 돌고, 그 점선이 지나간 자리가 곧 통과로입니다. 원반 뒤의 고리는 공중에 선 원인데, 접선 방향으로 늘인 불꽃을 매 프레임 스스로에게서 던집니다. 통과로는 샌드박스에서 **광을 채우는 대신 입구를 가져가는** 유일한 관문입니다.

![불꽃 차원의 문 — 공중에 찍힌 검은 디스크, 고리에서 던져지는 불꽃](docs/screenshots/fire-portal.jpg)

준비-시전 루프 바깥에 자기 강화가 셋 있습니다. **B** 전기 강화, **M** 마법 강화, **K** 불꽃 강화. 셋 다 선택되지 않고 조준되지도 않으며, 셋 중 아무거나, 전부, 혹은 아무것도 켜져 있지 않을 수 있습니다.

![전기, 마법, 불꽃 강화가 동시에 켜진 모습](docs/screenshots/self-buffs.jpg)

보이는 모든 것은 생성됩니다. 스프라이트 시트도 없고 디스크 위의 메시도 캐릭터 외에는 없습니다. 칼날은 절차적 지오메트리, 다리는 정점 셰이더에서 완전히 구부린 절차적 튜브, 전기 아크는 인스턴스 리본, 판과 돌과 관문 블록은 절차적 지오메트리, 관문을 통과하는 빛줄기와 불꽃 차원의 문의 구멍은 한 쿼드의 두 패스, 화살표와 조준 원과 그을음과 녹은 균열은 부호 거리 함수와 노이즈 셰이더, 안개와 불꽃과 숯과 먹물과 파편은 GPU 파티클입니다.

**모든 매개변수는 실시간 슬라이더**이며 일시정지 중에도 그대로 작동합니다. 이 프로젝트의 요지는 그것입니다 — **P**로 분출 도중, 내리치는 도중, 타오르는 도중 한 프레임을 멈춘 다음, 정지된 이미지에 맞춰 실루엣과 팔레트와 타이밍을 다시 만져보세요.

### 자산

바이너리 자산은 `public/`에 있으며 부팅 시 자동으로 불러옵니다:

| 파일 | 용도 |
| --- | --- |
| `public/models/Idle.fbx` | 리깅된 캐릭터 **그리고** 그 idle 애니메이션 클립 |
| `public/models/diffuse.png` | 캐릭터의 컬러 맵 |
| `public/models/cast1.fbx` | 시전 애니메이션 |
| `public/models/cast2.fbx` | 시전 애니메이션 |
| `public/models/cast3.fbx` | 시전 애니메이션 |
| `public/hdri/spruit_sunrise.hdr` | 이미지 기반 조명과 반사에 쓰이는 HDR 프로브 |
| `public/textures/cathedral/*.jpg` | 무대 바닥을 장식하는 석재 타일링 (albedo, normal, roughness, AO) |
| `public/textures/textures.glb` | 캐릭터 스킨 폴백으로 보관된 작은 머터리얼 라이브러리 |

네 FBX 파일은 모두 같은 리그를 Mixamo에서 내보낸 것으로, 스킨 메시와 애니메이션 스택 한 개씩을 담고 있습니다. 캐릭터는 idle 파일이 가져오고, 시전 파일은 클립만 가져오며, 각 파일과 함께 들어오는 중복 리그는 `AnimationClip`만 빼내면 바로 해제합니다. 클립은 본 이름으로 뼈대에 묶이므로, 다른 파일에서 만든 애니메이션이라도 리타기팅 없이 그대로 재생됩니다.

리그에는 머터리얼이 없으므로 `diffuse.png`를 함께 불러와 임포트 직후 PBR로 변환한 머터리얼에 컬러 맵으로 할당합니다. FBX 안에 텍스처가 들어 있는 경우는 자기 UV에 맞춰 작성된 그 텍스처를 그대로 둡니다.

모든 능력은 던질 클립을 스스로 고릅니다 — 설정 블록의 `castAnim`, 에디터 폴더의 "**시전**" 아래 드롭다운이 그것입니다. 클립은 idle 위에 한 번만 얹는 1회성이고, `character.castBlendIn` / `character.castBlendOut`이 그 겹침의 양쪽 끝입니다.

HDR은 이미지 기반 조명으로, 그리고 전기 구체와 마법 강화 리본의 반사 소스로 불러옵니다. 무대는 평평한 어두운 배경을 유지하고, HDR은 샘플링만 할 뿐 보여주지 않습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| **Q** (또는 **1**) | 화염 왕관 — 원거리 시전, 원으로 조준 |
| **E** (또는 **2**) | 크라켄 왕관 — 원거리 시전, 원으로 조준 |
| **R** (또는 **3**) | 전기 구체 — 원거리 시전, 원으로 조준 |
| **F** (또는 **4**) | 대지의 첨탑 — 라인 시전, 화살표로 조준 |
| **V** (또는 **5**) | 녹색 관문 — 관문 시전, 문지방과 서 있는 아치로 조준 |
| **X** (또는 **6**) | 격류의 고리 — 고리 시전, 고리가 기울어지는 시길로 조준 |
| **Z** (또는 **7**) | 불꽃 차원의 문 — 필기 시전, 불꽃이 도는 원으로 조준 |
| **B** | 전기 강화 — 자기 강화; 다시 누르면 해제 |
| **M** | 마법 강화 — 자기 강화; 다시 누르면 해제 |
| **K** | 불꽃 강화 — 자기 강화; 다시 누르면 해제 |
| **마우스 이동** | 조준 화살표를 휘두르거나, 원거리 시전 원을 움직임 |
| **좌클릭** | 화살표 방향으로 시전하거나, 현재 위치에 원을 떨어뜨림 |
| **Esc** / **우클릭** | 시전 능력 취소 |
| **우드래그** | 카메라 궤도 회전 |
| **스크롤** | 줌 |
| **G** | VFX 에디터 표시/숨김 |
| **P** | 일시정지 / 재개 — *에디터는 계속 적용됨* |
| **C** | 모든 활성 효과 정리 |
| **H** | 조작 안내 패널 숨김 |

`range` 와 `minRange`는 능력별이므로, 선택한 슬롯에 따라 조준 표시의 사거리가 달라집니다. 선택한 능력의 `minRange`보다 가까이 조준하면 빨갛게 표시되고 시전이 거부됩니다. `minRange`를 0으로 두면 자기 발 아래로 시전할 수 있게 되는데, 화염 왕관이 기본값으로 채택하는 방식입니다 — 자기 발 둘레의 불의 고리도 정당한 플레이입니다. 쿨다운도 능력별로, 한 슬롯을 써도 다른 슬롯이 잠기지 않습니다.

세 강화는 슬롯이 아닙니다. 아무것도 그것들을 선택하지 않고 아무것도 그것들을 조준하지 않으므로, 준비-시전 루프 바깥에 있으며 그냥 켜고 끄는 것으로 작동합니다. 셋 중 아무거나, 전부, 혹은 아무것도 켜져 있을 수 있습니다 — 둘이 캐릭터 자신의 머터리얼에 빛을 비추려 할 때는 더 강한 쪽이 이깁니다 (`src/materials/FresnelAura.js` 참조). 불꽃 강화는 효과를 어디에 걸지에서 다른 두 개와 다릅니다 — 불이 리그의 **실제 본**에 뿌리내려 전완의 불이 팔과 함께 흔들리고, 궤도를 도는 숯은 그 궤적을 시간으로 **역재생한** 자취를 남깁니다 — 기울기를 끌어당기면 일시정지 중에도 1초 분량의 불이 다시 그려집니다.

## 프로젝트 구조

```
src/
  abilities/      Ability 베이스 클래스 (여행하는 전면, 단계 머신, 광 부기),
                  PyreAbility, KrakenAbility, ElectricalSphereAbility, EarthAbility,
                  PortalAbility, AetherRingAbility, FirePortalAbility, AbilityManager
  animation/      FBX 캐릭터 불러오기, AnimationMixer, 능력별 시전 클립,
                  절차적 시전 돌진
  assets/         절차적 지오메트리: 수정, 판, 블록, 바위, 탑, 팔, 볼트 리본 스트립
  config/         settings.js — 모든 매개변수의 단일 진실 원천
  core/           App, Renderer, CameraRig, Time, Layers, 공유 프레임 uniform
  effects/        조준 화살표, 원거리 원, 관문/고리/필기 템플릿, 도달 고리,
                  바닥 데칼, 균열, 폭발, 빛 웅덩이, 세 강화,
                  흔들림, 섬광
  input/          InputManager (이벤트) 그리고 AimController (다섯 가지 조준 형태)
  loaders/        공유 LoadingManager를 갖춘 AssetLoader
  materials/      PyreMaterial, KrakenMaterial, ElectricalSphereMaterial, RockMaterial,
                  GlassMaterial, RadialBoltMaterial, EmberFieldMaterial, AbyssFieldMaterial,
                  FireBodyMaterial, FresnelAura, ArcaneRibbonMaterial
  particles/      GPU 파티클 시스템 + 엔진 + 비율 이미터
  postprocessing/ Composer 파이프라인, 그레이드 셰이더
```
